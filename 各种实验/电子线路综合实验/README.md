这个实验主要是培养一些动手搭电路以及调试的基础实践能力，基本上实验的电路图都会给大家，也就是说大家最主要的就是能看明白图然后能自己动手搭出来就可以了，更进一步的，可以自己去了解一下实验电路的原理，其实还是能学到很多东西的。

所以实验的难点，更多在于硬件的不确定性，比如一些二手元器件是否能正常工作，特别是包括面包板，因为使用时间比较长，有些面包板的某些位置可能会出现非预期的短路或者断路，这可能会让初次接触的大家难以招架。那么再说回来，其实这一方面也就是要求大家掌握一定的调试差错的能力，那么这个能力就首先需要大家能看明白原理了，所以我说大家能把这些电路都理解的话，一定能学到一些实用的东西，做实验也肯定的事半功倍的。

最后的大实验，数字钟，也是同理，依旧是各种模块拼接而成，最后总共的工作量不算少，所以如果你运气不好的话调试起来还是需要一些耐心的。有关我的实验报告，最后做了一个拓展功能是动态显示，在数电教材上就有详细的介绍，大家想要尝试和进一步拓展的可以借鉴。
