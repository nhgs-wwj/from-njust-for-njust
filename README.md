# from-njust-for-njust

## 内容说明

本仓库整理本科期间部分的课程实验、工程代码、复习资料和个人经验（经验贴部分仍在整理，完善后会更新），主要用于学习参考和经验传承。

另外，涉及到老师的权益，故我这里不会留存老师上课的PPT以及对应不公开的资料等。

资料对应的课程、教师、实验设备和要求可能随年份变化，请以当学期的课程要求为准。

## 使用提醒与免责声明

仓库中的实验报告、代码、数据和复习资料不保证完全正确，也不应直接替代自己的实验过程或课程作业，因雷同或查重导致的学术不端后果自负。

部分内容由多人协作完成，部分内容使用过 AI 辅助，也有一些资料来自公开项目或课程参考材料。使用时请自行核验。

因为我的实验报告我还算是比较认真的，除了时间太紧或者我认为实验意义不大，纯AI或者很敷衍的情况几乎不会有，实验中我遇到的实际问题或者是一些真实的心得体会我也会记录下来，所以大家也可以根据我的报告进行一个简单的预习，就是可以大致的看看我的实验操作以及总结部分，有没有提到一些坑等等，大家可以提前准备。如果你看的过程中发现那一部分是AI的，那么你就当我没说好了。。。

提交 Issue 时请写明文件路径、具体问题或者复现方式等等。
